# استاندارد محتوا

هر کتاب باید عنوان، معرفی، سه پروژه پیشنهادی، شش مرحله و مسیر Portfolio داشته باشد.

هر مرحله باید شامل نوع و زمان، عنوان، توضیح، سه هدف، محتوای مفهومی، مثال کد، خروجی مورد انتظار، تمرین Hidden Test، Quiz، Mistake Lab، جمع‌بندی و اتصال به پروژه باشد. مرحله ششم پروژه پایانی است.

ادعاهای نتیجه بدون شاهد ممنوع‌اند؛ داده Synthetic باید صریح معرفی شود؛ Correlation نباید Causation معرفی شود؛ Web Scraping فقط روی منابع مجاز آموزش داده می‌شود.
