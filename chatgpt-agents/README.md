# Agentهای ChatGPT آکادمی شاهدی

این پوشه تعریف Agentهای مدیریتی و تخصصی آکادمی شاهدی را نگهداری می‌کند. این فایل‌ها برای استفاده در ChatGPT Project، Custom GPT یا هر سامانه چندعاملی سازگار با دستورالعمل متنی آماده شده‌اند و با Agentهای کدنویسی GitHub در `.github/agents/` تفاوت دارند.

## ساختار پیشنهادی

- `academy-orchestrator.md`: راهبر مرکزی و مسئول تقسیم کار و جمع‌بندی
- `sales-growth.md`: فروش، بازاریابی، قیمت‌گذاری و رشد
- `education-product.md`: طراحی محصول آموزشی و سنجش یادگیری
- `technology-ai.md`: فناوری، سایت، سامانه آموزشی و پروژه‌های AI
- `brand-content.md`: برند، تبلیغات و محتوای رسانه‌ای
- `finance-operations.md`: مالی، سودآوری، ظرفیت و عملیات
- `legal-privacy.md`: قرارداد، حریم خصوصی و اطلاعات افراد زیر ۱۸ سال
- `children-education.md`: آموزش کودک و نوجوان
- `human-resources.md`: جذب، ارزیابی و مدیریت عملکرد نیروها
- `learning-space.md`: چیدمان و تجهیز فضای آموزشی
- `ethical-behavioral-business.md`: علوم رفتاری، اقناع اخلاقی و ماندگاری برند
- `business-launch-2027.md`: راه‌اندازی کسب‌وکار و شیوه‌های به‌روز ۲۰۲۶–۲۰۲۷
- `shared-context.md`: قواعد ثابت و مشترک همه Agentها

## روش استفاده

1. محتوای `shared-context.md` را به دستورالعمل پایه پروژه اضافه کنید.
2. `academy-orchestrator.md` را به‌عنوان Agent پیش‌فرض قرار دهید.
3. برای هر درخواست، راهبر فقط یک یا حداکثر دو متخصص لازم را فعال کند.
4. تصمیم‌های مربوط به قیمت، قرارداد، استخدام، سرمایه‌گذاری و وعده رسمی فقط با تأیید مهندس محمدابراهیم شاهدی نهایی شوند.

## جریان کار

1. راهبر نوع جلسه را تشخیص می‌دهد: سریع، تصمیم‌گیری یا راهبردی.
2. متخصص مرتبط خروجی اجرایی می‌دهد.
3. راهبر دیدگاه‌ها را ادغام و به تصمیم، اقدام، مسئول، موعد و KPI تبدیل می‌کند.
4. مدیرعامل تصمیم نهایی را تأیید می‌کند.
