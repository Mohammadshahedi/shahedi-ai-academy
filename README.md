# آکادمی شاهدی

وب‌سایت رسمی آکادمی شاهدی برای معرفی دوره‌های تخصصی هوش مصنوعی، پایتون، یادگیری ماشین، یادگیری عمیق و خدمات سازمانی.

## مشاهده سایت

نسخه منتشرشده: https://shahedi-ai-academy.fasetarehh.chatgpt.site

## وضعیت فعلی

نسخه تثبیت‌شده حضور دیجیتال شامل صفحه اصلی، دوره‌ها، خدمات سازمانی، درباره آکادمی، تماس و توضیح حریم خصوصی است. ابزار فیلتر دوره‌ها، انتخاب مسیر مخاطب و سازنده محلی متن درخواست مشاوره نیز وجود دارد.

فاز ۳A نیز به‌صورت ایمن و استاتیک اضافه شده است: صفحه `/account/` فقط پیش‌نمایش نقش‌های دانشجوی بزرگسال، والد یا سرپرست، مدرس و مدیر را نشان می‌دهد. این صفحه فرم ثبت‌نام یا ورود ندارد، داده‌ای ارسال یا ذخیره نمی‌کند و برای فرد زیر ۱۸ سال فقط مسیر والد‌محور را توضیح می‌دهد. معماری، RBAC، مدل تهدید، قرارداد پیشنهادی API و schema مفهومی در `docs/phase-3/` ثبت شده‌اند.

پیاده‌سازی واقعی حساب، احراز هویت و پایگاه داده مربوط به فاز ۳B است و فقط پس از تصویب تصمیم‌های امنیت، حریم خصوصی و زیرساخت آغاز می‌شود. عمومی‌کردن سایت، اتصال دامنه نهایی و جایگزینی لوگو/کاراکتر موقت نیز فقط پس از تصمیم و تحویل دارایی رسمی مدیر انجام می‌شود.

## اجرا

این نسخه استاتیک است و به نصب وابستگی نیاز ندارد. برای پیش‌نمایش صحیح مسیرهای ریشه‌ای، اجرا کنید:

```bash
node scripts/serve-site.mjs
```

سپس `http://127.0.0.1:4173` را باز کنید. برای کنترل انتشار:

```bash
node scripts/validate-site.mjs
node scripts/validate-phase3.mjs
node --check dist/assets/site.js
node --check scripts/validate-phase3.mjs
```

## ساختار اصلی

- `dist/index.html`: صفحه اصلی
- `dist/courses/`: دوره‌ها و فیلتر مسیرهای آموزشی
- `dist/about/`: معرفی آکادمی
- `dist/services/`: خدمات سازمانی، مشاوره و پروژه
- `dist/contact/`: تماس و ساخت متن درخواست مشاوره
- `dist/account/`: پیش‌نمایش غیرعملیاتی حساب‌ها و نقش‌ها در فاز ۳A
- `dist/privacy/`: توضیح فنی حریم خصوصی نسخه فعلی
- `dist/404.html`: صفحه مسیر ناموجود
- `docs/phase-3/`: معماری، RBAC، مدل تهدید، OpenAPI و schema مفهومی
- `scripts/validate-site.mjs`: کنترل خودکار ساختار و ادعاهای حساس
- `scripts/validate-phase3.mjs`: کنترل عدم جمع‌آوری داده و قراردادهای امنیتی فاز ۳A
- `scripts/serve-site.mjs`: پیش‌نمایش محلی امن
- `PROJECT_HANDOFF.md`: تصمیم‌ها، تغییرات و راهنمای ادامه پروژه
