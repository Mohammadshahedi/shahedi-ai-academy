# آکادمی شاهدی

وب‌سایت رسمی آکادمی شاهدی برای معرفی دوره‌های تخصصی هوش مصنوعی، پایتون، یادگیری ماشین، یادگیری عمیق و خدمات سازمانی.

## مشاهده سایت

نسخه منتشرشده: https://shahedi-ai-academy.fasetarehh.chatgpt.site

## وضعیت فعلی

نسخه تثبیت‌شده فاز اول حضور دیجیتال شامل صفحه اصلی، دوره‌ها، خدمات سازمانی، درباره آکادمی، تماس و توضیح حریم خصوصی است. ابزار فیلتر دوره‌ها، انتخاب مسیر مخاطب و سازنده محلی متن درخواست مشاوره نیز وجود دارد.

کد این نسخه برای انتشار آماده است؛ عمومی‌کردن سایت، اتصال دامنه نهایی و جایگزینی لوگو/کاراکتر موقت فقط پس از تصمیم و تحویل دارایی رسمی مدیر انجام می‌شود.

## اجرا

این نسخه استاتیک است و به نصب وابستگی نیاز ندارد. برای پیش‌نمایش صحیح مسیرهای ریشه‌ای، اجرا کنید:

```bash
node scripts/serve-site.mjs
```

سپس `http://127.0.0.1:4173` را باز کنید. برای کنترل انتشار:

```bash
node scripts/validate-site.mjs
node --check dist/assets/site.js
```

## ساختار اصلی

- `dist/index.html`: صفحه اصلی
- `dist/courses/`: دوره‌ها و فیلتر مسیرهای آموزشی
- `dist/about/`: معرفی آکادمی
- `dist/services/`: خدمات سازمانی، مشاوره و پروژه
- `dist/contact/`: تماس و ساخت متن درخواست مشاوره
- `dist/privacy/`: توضیح فنی حریم خصوصی نسخه فعلی
- `dist/404.html`: صفحه مسیر ناموجود
- `scripts/validate-site.mjs`: کنترل خودکار ساختار و ادعاهای حساس
- `scripts/serve-site.mjs`: پیش‌نمایش محلی امن
- `PROJECT_HANDOFF.md`: تصمیم‌ها، تغییرات و راهنمای ادامه پروژه
