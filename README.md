# آکادمی شاهدی

وب‌سایت رسمی آکادمی شاهدی برای معرفی دوره‌های تخصصی هوش مصنوعی، پایتون، یادگیری ماشین، یادگیری عمیق و خدمات سازمانی.

## مشاهده سایت

نسخه منتشرشده: https://shahedi-ai-academy.fasetarehh.chatgpt.site

## وضعیت فعلی

نسخه تثبیت‌شده حضور دیجیتال شامل صفحه اصلی، دوره‌ها، خدمات سازمانی، درباره آکادمی، تماس و توضیح حریم خصوصی است. ابزار فیلتر دوره‌ها، انتخاب مسیر مخاطب و سازنده محلی متن درخواست مشاوره نیز وجود دارد.

فاز ۳A به‌صورت سند و آرشیو پیش‌نمایش در `docs/phase-3/` و `legacy-static/account/` حفظ شده است.

فازهای ۳B.1 و ۳B.2 در کد اجرا شده‌اند: پروژه از انتشار استاتیک به Vinext Worker مهاجرت کرده و هویت مدیریت‌شده Sites، D1، حساب بزرگسال، RBAC سمت سرور، audit، محدودیت نرخ، پنل مدیریت، bootstrap مدیر نخست، دعوت امن کارکنان و lifecycle درخواست حذف را دارد. آکادمی رمز عبور ذخیره نمی‌کند و نقش مدرس یا مدیر از ثبت‌نام عمومی صادر نمی‌شود.

برش **۳B.۳–آماده‌سازی** یک صفحه خصوصی و فقط‌خواندنی برای مشاهده موانع حقوقی و عملیاتی اضافه می‌کند. این برش اجرای کامل ۳B.۳ نیست؛ هیچ داده کودک، مدرک سرپرستی یا رضایتی دریافت نمی‌کند و مسیر مربوط همچنان پیش از خواندن payload با پاسخ `423` بسته می‌ماند.

فاز **۳C.۱** هسته LMS فقط بزرگسالان را اضافه می‌کند: دوره و درس text-only، کلاس، assignment مدرس، enrollment مدیریتی، فضای `/learn/` دانشجو و نمای بدون roster مدرس. این فاز هیچ قیمت، پرداخت، ظرفیت، تاریخ، شهر، گواهینامه، تمرین، نمره، analytics یا داده کودک ندارد.

فاز **۳C.۲** چرخه عمر نسخه‌دار همین منابع را اضافه می‌کند: ساخت با وضعیت اولیه امن، transitionهای مجزا، کنترل `expectedVersion`، eventهای append-only، audit اتمیک و تاریخچه خصوصی بدون PII/محتوا. مرز فقط بزرگسالان و قفل داده کودک بدون تغییر باقی مانده است.

فاز **۳C.۳** revisionهای immutable محتوای درس و انتشار نسخه‌محور را اضافه می‌کند؛ legacy بدون pointer فقط fallback خواندنی دارد و انتشار تازه بدون revision متعلق به همان درس مسدود است.

در پنل مدیر، ساخت revision به‌تنهایی محتوای دانشجو را تغییر نمی‌دهد. انتشار یا بازگردانی با `expectedLessonVersion` انجام می‌شود و دانشجو فقط revision اشاره‌شده را می‌خواند.

فاز **۳C.۴** سه عملیات نسخه‌دار موجود را در پنل مدیر تکمیل می‌کند: اصلاح عنوان دوره، عنوان کلاس و جایگاه درس. منابع نهایی فقط‌خواندنی‌اند، تعارض نسخه retry خودکار ندارد و عنوان/متن درس همچنان فقط از revision تغییر می‌کنند. این فاز schema یا migration تازه ندارد.

دریافت داده فرد زیر ۱۸ سال تا تصویب سیاست رضایت، روش اثبات سرپرستی، نگهداری و حذف داده با پاسخ fail-closed مسدود است. حذف فیزیکی حساب نیز تا تصویب نسخه نگهداری داده انجام نمی‌شود. ارسال خودکار ایمیل برای دعوت انتخاب نشده و token دعوت فقط یک‌بار در پنل خصوصی مدیر نمایش داده می‌شود.

## اجرا

پروژه به Node.js 22 یا جدیدتر نیاز دارد. برای نصب قفل‌شده و کنترل کامل اجرا کنید:

```bash
npm ci
npm run check
npm run db:generate
npm run build
```

برای migration محلی D1، پس از build فایل migration را طبق راهنمای `docs/phase-3b/IMPLEMENTATION.md` اعمال کنید. انتشار فقط پس از دستور صریح مدیر انجام می‌شود.

```bash
npm run check
npm run build
```

## ساختار اصلی

- `app/account/`: ورود مدیریت‌شده و onboarding حساب بزرگسال
- `app/dashboard/`: داشبورد اولیه نقش‌محور
- `app/admin/`: bootstrap، پنل مدیریت حساب و صفحه فقط‌خواندنی آمادگی ۳B.۳
- `app/admin/lms/`: پنل خصوصی مدیریت LMS بزرگسالان
- `app/admin/lms/lessons/[lessonId]/revisions/`: مدیریت و انتشار revisionهای immutable درس
- `app/learn/` و `app/teach/`: فضای نقش‌محور دانشجوی بزرگسال و مدرس
- `app/staff-invitation/`: پذیرش دعوت با ایمیل تأییدشده پلتفرم
- `app/api/`: API حساب، مدیریت و دروازه قفل‌شده کودک
- `db/schema.ts`: مدل اجرایی D1 برای حساب، نقش، رضایت و حسابرسی
- `drizzle/`: migration نسخه‌دار D1
- `legacy-static/`: منبع صفحات معرفی تثبیت‌شده و آرشیو پیش‌نمایش ۳A
- `lib/`: سرویس حساب، کنترل درخواست، نرخ و تصمیم‌های سیاستی
- `docs/phase-3/`: معماری، RBAC، مدل تهدید، OpenAPI و schema مفهومی
- `docs/phase-3b/`: تصمیم‌های اجرایی، روش آزمون و محدودیت‌های انتشار
- `scripts/validate-phase3b.mjs`: کنترل D1، هویت، RBAC و قفل کودک
- `scripts/validate-phase3b2.mjs`: کنترل migration افزایشی، دعوت تک‌مصرف و حفاظت آخرین مدیر
- `scripts/validate-phase3b3.mjs`: کنترل قفل fail-closed، immutable بودن migrationها و فقط‌خواندنی‌بودن صفحه آمادگی
- `scripts/validate-phase3c1.mjs`: کنترل migration، RBAC، API و مرز بزرگسالان ۳C.۱
- `scripts/validate-phase3c2.mjs`: کنترل immutable migrationها، matrix گذار، optimistic lock، batch اتمیک و تاریخچه ۳C.۲
- `scripts/validate-phase3c3.mjs`: کنترل revision/publication، ownership، race و خواندن pointerمحور ۳C.۳
- `scripts/validate-phase3c4.mjs`: کنترل UI اصلاح فراداده، قرارداد PATCH، migrationهای immutable و قفل کودک
- `PROJECT_HANDOFF.md`: تصمیم‌ها، تغییرات و راهنمای ادامه پروژه
